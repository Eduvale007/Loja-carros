# Loja-Carros

**Loja-Carros** é uma página HTML criada para apresentar e vender veículos, oferecendo informações detalhadas sobre modelos, preços e características de cada carro.

---

## Sobre o Projeto

O objetivo da Loja-Carros é fornecer uma **experiência visual clara e organizada** para clientes que desejam conhecer e adquirir veículos. A página apresenta:

- Catálogo de carros com imagens e descrições  
- Informações sobre preços e especificações  
- Layout moderno e responsivo, acessível em diferentes dispositivos  
- Interface simples e intuitiva para fácil navegação  

---

## Tecnologias Utilizadas

- HTML5  
- CSS3  

> Futuras versões poderão incluir **JavaScript** para interatividade e funcionalidades adicionais, como filtros de busca e carrinho de compras.
